## 0. 一句话概括

2026-10-27 18:13 到 2026-10-28 13:00，跨一夜，约 19 小时。
一个人提需求、看画面、拍板；一个 AI 写代码、打包、自测。

而这两件事恰好是 AI 当时做不了的部分（后面第 5 节会看到，凡是 AI 自己"看"出来的结论，
错得最多的就是对手感的判断）。

## 2. 第一个问题

**2026-10-27 18:13**

> 要一个放在 Windows 桌面上的天气卡片，视觉照苹果天气那套来 —— 渐变玻璃、7 天彩色温度条，
> 先做成能直接打开看效果的单文件网页。

上面这句是当时的理解与随之产出的规格，不是逐字原话（原始那句在会话压缩时丢了，所以不打引号）。
紧接着的第二句是原话：

> 「再简洁一点。」（18:48）

从"8 块玻璃卡 + 8 个指标格 + 星空光斑"砍到"只有一块玻璃 + 无框小时 + 4 个指标"。
这是这个项目的第一条规律：**他第一次说的通常是"要什么风格"，第二次说的才是"要多少东西"。**

之后从网页版变成真正贴在桌面上的 Electron 窗口，起因是一句很朴素的判断：
网页再好看也是一块方方正正的窗口，不像桌面上长出来的东西。

## 4. 他其实只在改三件事

十二个版本看起来零碎，归拢起来只有三类诉求，而且几乎按固定顺序循环：

1. **占多少桌面** —— 从"8 块玻璃"到"只剩几条框"。每一次都在减少存在感：砍指标、砍标题、
   砍统计、砍背景、砍到"一条待办都没有时整张卡就是一行输入框"。
2. **能不能挪、挪得顺不顺手** —— 拖不动 → 能拖了 → 抓手看着别扭 → 顶栏当标题栏 → 拖动时只剩框。
   这一条改了四版，是全项目返工最多的。
3. **看不看得清、优不优雅** —— 深色玻璃底、按钮钉住不动、展开时条目不许跳。

**需求没有跑偏过，跑偏的是我的实现。** 他每次说的都很具体（"加号会跑"、"要点一下才到前面"），
没有一次是"感觉不对，你再想想"。这对 AI 是好事：能定位；也是坏事：修到第 4 遍才明白他要的
不是"能拖"，而是"拖的时候像一个 Windows 窗口"。

## 5. AI 在过程中犯的错

这一节是这份文档存在的真正理由。共 13 条，按后果排序，不美化。

### 5.1 把 bug 写成了断言（最严重）

v1.6.0 的 `verify-solo.js` 里有这么一条：

```js
ok("＋ 被图标挤左边了", hv.btn.l < s.btn.l);
```

我把"悬停时 ＋ 被推左 80px"当成了**预期行为**写进断言。于是 39 条测试全绿，
而用户点不到按钮。是他手动试出来的。

教训：**断言要写"用户能不能点中"，不是"布局有没有按我的实现移动"。**
凡是断言描述"某元素被挤走/变形/抬起"的，都要反问一句 —— 这是用户想要的吗？
这条错误已反转为「＋ 一个像素都不许动」。

### 5.2 透明窗口带 `backgroundMaterial:"none"`

想关掉系统材质，很自然地传了 `"none"`。结果窗口仍走材质合成，页面内容被压成几乎不可见的一层
（截图上只剩隐约两个字）。真因：**这个字段只要存在就进合成管线，哪怕值是 none**。
正确写法是干脆不带这个键。

### 5.3 双击用原生 `dblclick`

条目要防拖选文字，`mousedown` 里 `preventDefault()`。这个调用把浏览器合成的 `dblclick`
一起吃掉 —— 双击永远不触发。改成自己判（间隔 <420ms、位移 <6px）。

### 5.4 按 Esc 反而保存了

Esc 收尾时把编辑框从 DOM 摘掉，**摘除正握着焦点的元素会立刻甩一个 blur**，
正好命中自己写的"失焦即保存"。修法：blur 处理里先核 `editId === el.dataset.id`。

### 5.5 以为 `setAlwaysOnTop` 能让窗口浮上来

用户说「需要鼠标点击它一下，它才会在前面」。我补了 `setAlwaysOnTop` —— 没用，z 序一个像素没动。
真因：**它只打样式，不改变窗口在置顶层内部的先后**。补 `moveTop()` 才真的翻上去。
更难看的是：这条是用户第二次反馈才修对的（第一次我以为已经修好了）。

### 5.6 测试落点选错，然后宣布"功能没实现"

v1.9.0 验中键拖动，脚本用"卡片底部往上一截"当落点 —— 那个位置正好是页脚。
中键事件根本没进拖动态，我一度判断"中键方案不可行"。改成按页面真实元素中心换算屏幕坐标后，一次就通。

### 5.7 把"加了不显示"当逻辑 bug 排查

用户说"点加号或回车，它就不显示在新任务里"。我跑了四条路径（卡外回车 / 点加号 / 打字回车 / 空点加号），
数据全部正确 +1。真实原因是**白字压在白色底的行情软件上**，整条隐形。
直到截了整屏才看见 —— 先看画面，再怀疑代码。

### 5.8 把 exe 秒退当成"包坏了"

打包后启动即退、参数报 bad option。折腾了一轮打包流程，真因是 shell 环境带着
`ELECTRON_RUN_AS_NODE=1`，exe 被当成 node 跑。启动前清掉这个变量即可。

### 5.9 把黑屏当成渲染 bug

截图全黑只看得到鼠标指针，差点去查 acrylic。真因：显示器休眠了。**截图全黑的时候先问屏幕状态。**

### 5.10 交付截图用了错的视口

v1.4.0 之前给我用户看的待办卡截图，固定 400px 高的视口 —— 看起来空一大截，
他据此提出"3 条占太大面积"。实际 3 条时 214px 已是最小。
**用自己的截图去证明"产品有问题"，等于向用户提了一个假需求。** 之后截图一律用真实内容高度做视口。

### 5.11 中文参数喂给 PowerShell 5.1

按窗口标题找窗口，脚本里写死中文标题 → 永远找不到。真因：PS 5.1 读**无 BOM 的 .ps1 按 ANSI 解析**，
中文字面量全成乱码。改成中文参数由 Node 传入、脚本输出只用 ASCII。

### 5.12 文档滞后于代码（两次）

v1.8.1 把拖动改回顶栏之后，README 里还写着"任务框可按住拖、光标是抓手、按住 0.26 秒微微抬起"。
另一条"浅色壁纸下对比度偏弱"在 v1.7.0 换深色玻璃底后已经不成立。
两次都是推到 GitHub 上看渲染效果才发现。**改了行为就要顺手改描述，不能等下次。**

### 5.13 交付顺序失误：让需要人动手的事过期了

GitHub 首次推送缺 `workflow` 权限，我发起了一个 15 分钟有效的设备授权码，然后**继续去做别的事**。
等回头时窗口已过期，只能重写全部 12 个提交把 CI 脚本摘出去（所有 commit hash 因此全变）。

教训：**凡"只有用户能做、且卡着后续"的事，必须第一时间单独交出去，不能排在最后。**

## 6. 他纠正我的三次，都不是逻辑错误

| 他说的 | 我的自测结论 | 真实情况 |
|---|---|---|
| 「那个加号不能到处跑」 | 39 条全绿 | 断言把 bug 当预期 |
| 「要点一下它才会在前面」 | setAlwaysOnTop 已调用，测试通过 | 只打样式没改层内顺序 |
| 「鼠标没出框框它就不该隐藏」 | mouseleave 逻辑正确 | 窗口变高时浏览器误报离开 |

三次的共同点：**代码"按逻辑"是对的，用户用手一摸就是不对。**
这也是为什么这个项目后来所有的验收都加了"真机真按键"那一层（`SetCursorPos` + `mouse_event`），
而不只是页面里的合成事件。

## 9. v1.0.0 拆分独立版（2026-10-28 下午）

用户决定：合体版到此为止，**天气和待办拆成两个独立项目、各自发布、本地安装包也各出各的**；此前发布的合体版 Release 全部删除。

- 仓库：`weather-widget`（本仓库，只保留天气卡）＋ 新仓库 `todo-widget`（只保留待办卡）
- 版本：两边都从 `1.0.0` 重新计（合体版历史保留在本仓库 git 与本文档里）
- 产物：`WeatherCard-1.0.0-x64-setup/portable.exe`、`TodoCard-1.0.0-x64-setup/portable.exe`
- 拆分方式：`main.js` / `preload.js` 各自裁剪成单卡版本（天气版去掉光标监视、自动高度、中键拖动；待办版去掉 Acrylic、IP 定位）；页面 HTML 零改动
- **数据迁移**：两个独立版首次启动都会把合体版 `%APPDATA%\weather-widget` 的存档搬过来 —— 窗口位置来自 `widget-state.json`，待办内容/历史来自 `Local Storage\leveldb` 整目录复制。已真机验证：位置与两条待办 + 历史全数到位
- 全局设置拆分：待办独立版右键菜单里补上了原来挂在天气卡菜单里的「桌面右键菜单显示」（注册表键改用 `TodoWidget`，与 `WeatherWidget` 互不冲突）和「开机自动启动」
- 踩坑：本机 agent 的 Bash/PowerShell 环境都带 `ELECTRON_RUN_AS_NODE=1`，直接 `electron .` 会被当成纯 Node 或被沙箱静默拦掉；PowerShell 里清掉该变量后一切正常。冒烟测试完删掉了测试生成的 `%APPDATA%\WeatherCard`、`%APPDATA%\TodoCard`，保证真实安装时重新走一遍干净迁移
